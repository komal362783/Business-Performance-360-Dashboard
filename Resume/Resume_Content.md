## Business Performance 360° Dashboard (CEO Dashboard) — GlobalMart Retail Inc.

---

## Project Description (100 words)

Built an end-to-end business intelligence solution for a simulated
multinational retailer, consolidating 100,000+ transaction records across 6
countries and 8 product categories into a unified analytics pipeline. Designed
a normalized SQL database and wrote 40 validated business queries; built a
430,000-formula Excel workbook with zero calculation errors; developed a
Python pipeline for data cleaning, feature engineering, and KPI generation;
and produced a complete Power BI dashboard specification (data model, 30 DAX
measures, 8 report pages). Delivered 27 data-driven insights and 15
prioritized recommendations, surfacing $5.8M in return-related profit
leakage and 42.5% of regions missing revenue targets.

## ATS-Friendly Resume Bullet Points

**Business Performance 360° Dashboard | Personal Data Analytics Project**
*SQL · Python (Pandas, NumPy, Matplotlib, Plotly) · Excel · Power BI (DAX)*

- Engineered a full-stack analytics pipeline processing 100,000+ retail
  transaction records across 6 countries, 8 product categories, and 4 sales
  channels, from raw data ingestion through executive dashboard delivery
- Designed and implemented a normalized relational database schema (8 tables,
  primary/foreign key constraints, indexed for performance) and authored 40
  business-critical SQL queries covering revenue, customer, product, regional,
  and returns analysis, validating each against a live database
- Built a production-grade data cleaning pipeline in both SQL and Python,
  resolving duplicate records, missing values, outliers, and inconsistent
  categorical labels across 100,000+ rows while maintaining full data lineage
  and audit trails
- Developed an interactive Excel workbook (16 sheets, 430,000+ live formulas)
  featuring INDEX/MATCH and VLOOKUP-based lookups, pivot-style summary tables,
  conditional formatting, and an executive KPI dashboard — validated to zero
  calculation errors via automated recalculation testing
- Performed exploratory data analysis and feature engineering in Python
  (Pandas/NumPy), deriving profit margin, delivery time, customer repeat-rate,
  and target-achievement metrics; produced 10+ static and interactive
  visualizations (Matplotlib, Plotly)
- Authored 30+ DAX measures and a complete 8-page Power BI dashboard
  specification (Executive Overview, Sales, Customer, Product, Regional,
  Profit, Returns, and Forecast pages) including drill-through, bookmarks,
  dynamic titles, and mobile layout design
- Generated 27 data-driven business insights and 15 prioritized executive
  recommendations directly from computed KPIs, identifying a $5.8M
  return-related profit leak and quantifying regional target performance
  across 30 regions
- Applied rigorous data-quality assurance throughout: caught and resolved a
  data-generation bug affecting product categorization, an inefficient Excel
  formula pattern causing calculation timeouts, and a misleading trend
  artifact in time-series data — documenting each fix transparently
